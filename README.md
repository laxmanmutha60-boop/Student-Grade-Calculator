# 🎓 Student Grade Calculator

A simple and user-friendly **Student Grade Calculator Web Application** built using **HTML, CSS, and JavaScript**.  
This project allows users to enter marks for different subjects and instantly calculate the **total marks, average percentage, and grade**.

---

## 📌 Features
- Easy and clean user interface
- Enter marks for 5 subjects
- Automatically calculates:
  - Total Marks
  - Average Percentage
  - Final Grade
- Instant result display without page reload
- Beginner-friendly web development project

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double click **index.html**.
4. The application will open in your browser.

---

## 📊 How It Works

1. Enter marks for all subjects.
2. Click the **Calculate** button.
3. The system calculates:
   - Total marks
   - Average marks
   - Grade based on the average.

---

## 🏆 Grade Criteria

| Average Marks | Grade |
|---------------|-------|
| 90 and above  | A     |
| 75 – 89       | B     |
| 50 – 74       | C     |
| Below 50      | Fail  |
